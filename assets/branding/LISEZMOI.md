# Identité visuelle CleanSlate

Logo : une ardoise ouverte nettoyée d'un trait (coche), dont les « pixels » s'envolent.
Couleurs : tuile sarcelle `#0F766E`, symbole `#F4FBFB`, texte `#1A1A1A` (ou blanc sur fond sombre).
Police du logotype : Inter SemiBold, vectorisée (aucune police requise pour l'afficher).

| Fichier | Usage |
| --- | --- |
| `cleanslate.ico` | Icône de l'exécutable, de la fenêtre, de la barre des tâches et de l'installeur. Contient 16, 20, 24, 32, 40, 48, 64, 96, 128 et 256 px, chaque taille dessinée nativement |
| `cleanslate-icon.svg` | Icône maître (tuile + symbole), à partir de 40 px |
| `cleanslate-icon-small.svg` | Variante simplifiée pour 16 à 32 px (cadre plus épais, 3 carrés) |
| `cleanslate-glyph-white.svg` | Symbole seul, blanc, sur fond sombre |
| `cleanslate-glyph-teal.svg` | Symbole seul, sarcelle, sur fond clair |
| `cleanslate-logo-horizontal.svg` | Icône + « CleanSlate », pour fond clair |
| `cleanslate-logo-horizontal-dark.svg` | Icône + « CleanSlate », pour fond sombre |
| `png/` | Exports PNG transparents des fichiers ci-dessus (icône de 16 à 1024 px) |

Règles :

- Ne pas déformer, recolorer ni ajouter d'ombre au logo.
- En dessous de 40 px, utiliser la variante `small` (ou l'`.ico`, qui la contient déjà).
- Garder autour du logo un espace libre d'au moins un quart de la hauteur de l'icône.
- Les SVG sont la source ; les PNG et l'ICO se régénèrent à partir d'eux.
